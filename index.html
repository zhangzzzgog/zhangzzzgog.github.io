Papers

2026
ACL
Accepted · First Author
Don't Click That: Teaching Web Agents to Resist Deceptive Interfaces
ACL 2026 Main Conference
Proposed DUDE, a two-stage VLM web agent defense framework combining hybrid-reward learning with asymmetric penalties and experience summarization. Introduced the RUC benchmark (1,407 real-world GUI scenarios, 4 domains). DUDE reduces deception susceptibility by 53.8% while maintaining task performance.
2025
USENIX
Published · Second Author
PAPILLON: Efficient and Stealthy Fuzz Testing-Powered Jailbreaks for LLMs
USENIX Security 2025
Automated black-box jailbreak framework adapting fuzz testing to LLMs: empty seed pool, dual-phase attack with three GPT-driven mutation strategies, and a two-level judge module. Achieves 90%+/80%+/74%+ ASR on GPT-3.5/GPT-4/Gemini-Pro, exceeding prior baselines by 60%+.
2026
NeurIPS
In Progress · First Author
Sparse Retrieval Memory for Long-Horizon LLM Agents
Target: NeurIPS 2026
Systematically analyzing memory architectures (SeCom, A-Mem, MemGAS) and identifying sparse retrieval as a core limitation under token budget constraints. Proposing an adaptive multi-granularity memory framework with a unified evaluation protocol across long-horizon planning, QA, and personalized dialogue.
