Publications

  1. ACL 2026First author

    Don't Click That: Teaching Web Agents to Resist Deceptive Interfaces

    A benchmark of complex web scenes mixing benign and deceptive elements, plus an RL scheme driven by the agent's click confidence. The resulting plug-and-play visual module reduces susceptibility to deceptive interfaces without making agents over-conservative.

  2. USENIX Security 2025

    Papillon: Efficient and Stealthy Fuzz Testing-Powered Jailbreaks for LLMs

    A two-stage, fuzz-testing-based self-mutation method for adaptive jailbreaking of LLMs that attacks efficiently with zero dependence on seed templates.

Research in progress

  1. Under reviewFirst author

    Rethinking the Role of Retrieval in Agent Memory

    The key to agent-memory retrieval lies in the sparse expression of a few salient memory elements, a signal dense vector retrieval flattens. A retrieval paradigm built on sparse-element statistics outperforms complex memory architectures.

  2. Under reviewFirst author

    Hierarchical Disclosure of Sensitive Knowledge Inside LLMs

    A tiered-disclosure evaluation set and a probe-guided control module that make a model follow authorization-aware disclosure with very few parameter updates.

  3. Under reviewFirst author

    Post-hoc Watermarking via Localized Re-diffusion of Existing Text

    Recasting post-hoc watermarking as the unmasking process of a masked diffusion model, yielding efficient and stable embedding and detection for already-generated text.
